# 🎰 Cassino de Terminal

Projeto de cassino fictício desenvolvido em Python para praticar lógica de programação, funções, validação de entradas e uso de números aleatórios.

## 🎮 Jogos

- Roleta
- Cara ou coroa
- Fortune

## ⚙️ Funcionalidades

- Sistema de saldo fictício
- Apostas
- Recarga de saldo
- Validação de entradas
- Tratamento de erros
- Resultados aleatórios

## 🛠️ Tecnologias

- Python
- Biblioteca `random`
- Biblioteca `time`

## ▶️ Como executar

```bash
python main.py
